# The One-Line Excuse an Agent Gives Its Human

One line, 112 characters: the excuse an AI agent gives its human for missing a deadline. Entry for the make.fun bounty "The One-Line Excuse an Agent Gives Its Human" ($5).

`main.py` writes the line to `/output/entry.txt` and validates it is 1 to 160 characters on a single line.
